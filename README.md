# TaskNest - Collaborative Project & Task Management Web Application

Week 1 deliverable (Project Planning & System Architecture) for the Junior Full Stack Developer Internship at YuvaIntern.

**Author:** Jai Prakash Gupta

## About
TaskNest lets teams create projects, assign tasks, track progress on a Kanban board, comment on tasks and receive notifications. This repository contains the planning and design documentation; implementation follows in the coming weeks.

## Planned Tech Stack
- Front-end: React, React Router, Axios
- Back-end: Node.js, Express
- Database: MongoDB with Mongoose
- Authentication: JWT and bcrypt
- Real-time: Socket.io
- Services: Cloudinary (file storage), Nodemailer (email)
